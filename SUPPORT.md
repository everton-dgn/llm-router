# Support

## Questions and troubleshooting

Read the project documentation and
[troubleshooting guide](docs/troubleshooting.md) first. If the problem remains,
open a
[question issue](https://github.com/everton-dgn/llm-router/issues/new?template=question.yml)
with the relevant versions, operating system, configuration with secrets
removed, and the exact error.

## Bugs

Use the
[bug report form](https://github.com/everton-dgn/llm-router/issues/new?template=bug_report.yml).
Include the smallest reproducible example and state whether the problem occurs
with deterministic tests or only with a live provider.

## Feature requests

Use the
[feature request form](https://github.com/everton-dgn/llm-router/issues/new?template=feature_request.yml).
Changes to routing contracts, policy schemas, or provider behavior should
include compatibility and migration considerations.

## Security and private reports

Follow [SECURITY.md](SECURITY.md). Vulnerabilities and confidential conduct
reports must not be posted in a public issue.

Support is provided by maintainers and the community on a best-effort basis.
There is no guaranteed response time for general questions or feature
requests.
